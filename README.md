# Hamoodh Mohideen — Student Portfolio

A responsive, minimal-premium student portfolio website with soft glassmorphism, CSS-built 3D orb artwork, project illustrations, and subtle scroll reveals.

## Preview locally
1. Unzip the folder.
2. Open `index.html` in a modern browser. For best results, use a small local server (e.g. VS Code Live Server).
3. Internet is only needed to load the Google Fonts; system fallbacks are included.

## Publish for free
- **GitHub Pages:** create a repository, upload the files in this folder, then enable Pages in repository Settings.
- **Netlify Drop:** drag the unzipped folder into Netlify's manual deploy area.
- **Replit:** create a static website project and upload these files.

Free-plan details can change. Check the host's current terms before publishing.

## Figma-ready design
`figma-design-board.svg` is an editable vector board. In Figma, create/open a design file and drag the SVG onto the canvas (or use File → Place image). Text and shapes in the imported SVG are vector objects; you can ungroup/edit them. It is a design reference board, not a native `.fig` file or a full auto-layout prototype.

Suggested Figma frame sizes:
- Desktop: 1440 × 1024
- Tablet: 834 × 1112
- Mobile: 390 × 844

## Edit your details
- Main content: `index.html`
- Colors, layout, responsiveness: `styles.css` (`:root` contains the main design tokens)
- Menu and reveal animations: `script.js`

## Accuracy and privacy notes
- The full street address was intentionally not displayed publicly; the site uses **Kuliyapitiya, Sri Lanka** as a general location.
- A/L results are marked “Results awaited” based on the supplied information.
- Project summaries are intentionally cautious and should be updated to match the exact implementation.
- Verify phone, email, LinkedIn URL, school name, achievement wording, and all public contact details before publishing.
- No grades, exam results, project performance claims, or other credentials were invented.

## Design system
- Canvas: `#F4F5F7`
- Primary ink: `#171A22`
- Secondary text: `#707684`
- Accent: `#8492BC`
- Glass: translucent white with blur and fine white borders
- Typography: Manrope (headings) + DM Sans (body)
